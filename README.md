# ERC-721
ERC-721 is a technical standard for creating and managing non-fungible tokens (NFTs) on the Ethereum blockchain. It's an open standard that defines how to build NFTs on the Ethereum Virtual Machine (EVM). 

Below are simple implementations of ERC-721 contracts with their deployment on Opensea Testnet:
- Codebase: [onchain-nft](https://github.com/Mosamorphing/ERC-721/tree/main/onchain-nft) Live link: [Opeansea](https://testnets.opensea.io/collection/yosemitenft)
- Codebase: [onchain-nft-II](https://github.com/Mosamorphing/ERC-721/tree/onchain-nft-II) Live link: [Opensea](https://testnets.opensea.io/collection/eden-22)
